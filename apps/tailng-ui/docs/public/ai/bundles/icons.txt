# TailNG icons

Install the package:

```bash
pnpm add @tailng-ui/icons
```

Register the built-in Lucide pack:

```ts
import { ApplicationConfig } from '@angular/core';
import { provideTngIcons } from '@tailng-ui/icons';

export const appConfig: ApplicationConfig = {
  providers: [provideTngIcons()],
};
```

Import and use the standalone component:

```ts
import { TngIcon } from '@tailng-ui/icons';
```

```html
<!-- Decorative when adjacent text provides the meaning. -->
<tng-icon icon="home" size="1.25rem" />

<!-- Meaningful standalone icon. -->
<tng-icon icon="search" label="Search" size="1.25rem" />
```

Unprefixed names use the default pack. Explicit references use `pack:name`, for example `lucide:star`.

Use `@tailng-ui/icons/core` when the application should register only explicitly imported icons and exclude the built-in registry. In that mode, provide at least one pack to `provideTngIcons`.
