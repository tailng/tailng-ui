# TailNG theme

The theme package has two complementary responsibilities:

- Runtime theme definitions and presets through `provideTailngTheme`.
- Component styling contracts through published CSS.

Most styled applications need both:

```ts
provideTailngTheme({ theme: defaultDarkThemePreset });
```

```css
@import '@tailng-ui/theme/index.css';
```

Read [runtime themes](https://tailng.dev/ai/theme/runtime.md) for preset application and [theme tokens](https://tailng.dev/ai/theme/tokens.md) for CSS customization.

# Runtime themes

Apply a preset in `app.config.ts`:

```ts
import { ApplicationConfig } from '@angular/core';
import { defaultThemePreset, provideTailngTheme } from '@tailng-ui/theme';

export const appConfig: ApplicationConfig = {
  providers: [provideTailngTheme({ theme: defaultThemePreset })],
};
```

Built-in exports include default, minimal, slate, nexus, prism, atlas, sterling, and daybook-classic presets, with light and dark variants where exported by the package.

Use `createTheme` or `mergeTheme` for programmatic theme composition. Use `toCssVars` when CSS variable output is needed outside the Angular provider.

# Theme tokens and contracts

Import the full component contract bundle:

```css
@import '@tailng-ui/theme/component-contracts/index.css';
```

Override shared control variables on `:root`, a theme scope, or a component subtree:

```css
:root {
  --tng-control-bg: var(--tng-semantic-background-surface);
  --tng-control-fg: var(--tng-semantic-foreground-primary);
  --tng-control-border: var(--tng-semantic-border-strong);
  --tng-control-radius: 0.5rem;
  --tng-focus-ring-color: var(--tng-semantic-focus-ring);
}
```

Prefer semantic and shared contract variables over selectors that depend on internal component markup. Scope an override to a component subtree when the change should not affect the whole application.
