# TailNG components

TailNG component products use standalone Angular components and directives exported from
`@tailng-ui/components`, `@tailng-ui/flow`, and selected `@tailng-ui/primitives` APIs.

The catalog below covers every official styled component product and every additional
top-level component exported by the package. Compound component symbols are documented
with their parent product.

### Feedback

- [Confetti component](https://tailng.dev/ai/components/confetti/overview.md): Controlled decorative paper bursts for successful actions and milestones.
- [Empty component](https://tailng.dev/ai/components/empty/overview.md): Empty-state layout with icon, title, description, and action composition.
- [Progress Bar component](https://tailng.dev/ai/components/progress-bar/overview.md): Linear determinate and indeterminate loading states with aria semantics.
- [Progress Spinner component](https://tailng.dev/ai/components/progress-spinner/overview.md): Circular determinate and indeterminate loading states with aria semantics.
- [Skeleton component](https://tailng.dev/ai/components/skeleton/overview.md): Decorative placeholder blocks for loading layouts and content scaffolding.
- [Toast component](https://tailng.dev/ai/components/toast/overview.md): Stacked notification toasts with auto-dismiss timing, dismiss actions, and tone semantics.

### Flow

- [Flow Editor component](https://tailng.dev/ai/components/flow-editor/overview.md): Embeddable, controlled node editor for AI agents, automations, and executable workflows.
- [Flow Execution Graph component](https://tailng.dev/ai/components/flow-execution-graph/overview.md): Standalone workflow graph diagram for execution snapshots, node status, selection, and viewport control.
- [Flow Node Properties component](https://tailng.dev/ai/components/flow-node-properties/overview.md): Selected-node details and edit panel for metadata, ports, data templates, and immutable change requests.
- [Flow Workbench component](https://tailng.dev/ai/components/flow-workbench/overview.md): Ready-made flow shell with create, edit, view, inspect, and live modes plus optional palette and details panels.

For every component:

1. Import the component class into the consuming standalone Angular component.
2. Use the documented selector and public inputs.
3. Load the TailNG theme contract stylesheet.
4. Provide an accessible name where the component does not have visible labelling.
5. Run the Angular production build after integration.

Consult the [human component catalog](https://tailng.dev/components) for interactive examples and verify package compatibility in [the version manifest](https://tailng.dev/ai/versions.json) before installation.
