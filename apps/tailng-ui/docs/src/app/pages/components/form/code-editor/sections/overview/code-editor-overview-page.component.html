Code Editor overview

Code Editor combines a native textarea with an aria-hidden highlighted overlay. Editing, selection, clipboard, undo, and IME behavior remain native while highlighting stays adapter-based.

Imports and provider

The component works without a highlighter and renders escaped plain text by default.

Component boundaries

  • tng-textarea is for ordinary plain and multiline form text.
  • tng-code-editor is for editable source with optional highlighting.
  • tng-code-block is for read-only rendered source.

Accessibility baseline

  • The native textarea is the only interactive and accessibility surface.
  • The highlighted layer is always hidden from assistive technology.
  • Tab keeps its native focus-navigation behavior and is not trapped.
  • Readonly content remains focusable and selectable; disabled content does not.
