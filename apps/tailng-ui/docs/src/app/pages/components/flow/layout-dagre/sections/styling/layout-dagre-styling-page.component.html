Dagre Layout styling

Dagre calculates geometry and renders no UI. Style and size the Flow Editor canvas and node templates that supply the measured layout bounds.

Required styles

The adapter has no CSS entry point. Import the Flow Editor stylesheet once in the application global stylesheet.

Host sizing

Give the editor a stable nonzero height. Dagre uses the bounds measured from the rendered canvas, so a collapsed host cannot produce a useful layout.

Measured custom nodes

Dagre receives the actual rendered width and height of every node. Keep custom node dimensions deterministic and let long content wrap so repeated layout requests remain visually stable.

Viewport effects

Layout spacing values use canvas coordinates. The optional viewport fit changes only the camera after your application renders the requested positions; it does not change the Dagre geometry or node styles.
