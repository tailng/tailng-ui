Built-in fields

The default panel renders name, description, type, disabled state, locked state, input ports, output ports, and a readonly data preview.

Update model

Edits are emitted as immutable node change requests. The consuming application applies those requests to the workflow definition, which keeps validation, persistence, and collaboration rules outside the presentation component.
