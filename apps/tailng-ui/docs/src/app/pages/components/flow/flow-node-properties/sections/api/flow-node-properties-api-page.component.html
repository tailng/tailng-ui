Properties inputs

Provide either the selected node directly or a definition plus inspectedNodeId so the component can resolve the active node.

  • definition: workflow definition used for node lookup.
  • node: explicit selected node override.
  • inspectedNodeId: selected node id when using definition lookup.
  • readonly: disables edit controls.
  • showData and showPorts: toggle optional sections.

Properties outputs

Listen for nodeChangeRequested. The payload is a TngFlowNodePropertyChangeRequest with the node id, source field, and partial node changes to apply.

Data template

Project ng-template[tngFlowNodePropertiesData] when a product needs custom node data editing or a domain-specific readonly summary.
