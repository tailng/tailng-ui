Graph inputs

The required model inputs are definition and snapshot. The graph is otherwise controlled through the same state channels as the editor surface.

  • definition: workflow graph definition.
  • snapshot: run, node, and connection execution state.
  • selection, inspectedNodeId, and selectedExecutionId: controlled interaction state.
  • viewport: controlled pan and zoom state.
  • mode: inspect or readonly.
  • showControls, showBackground, showMinimap, showSelectionArea, and fitOnInit: surface feature toggles.

Graph outputs

Listen for selectionChange, inspectedNodeIdChange, selectedExecutionIdChange, viewportChange, and executionActivated to keep the product state synchronized.

Imperative helpers

The graph forwards layout and viewport helpers such as refreshLayout(), fitToScreen(), resetViewport(), and centerNode().
