Graph inputs

The required model inputs are definition and snapshot. The graph is otherwise controlled through the same state channels as the editor surface.

  • definition: workflow graph definition.
  • snapshot: run, node, and connection execution state.
  • selection, inspectedNodeId, and selectedExecutionId: controlled interaction state.
  • viewport: controlled pan and zoom state.
  • connectionCreationPathType: two-way model for the path shape used by the live connection preview and future connection requests. A null value resolves from connection defaults, then falls back to Bézier.
  • mode: edit, inspect, or readonly. This is the only graph interaction-mode input.
  • attachmentLayout="custom-points": displays three connection positions on each node border for free-form authoring. The default static-ports layout renders only ports declared by the workflow definition.
  • showControls, showConnectionTools, showBackground, showMinimap, showSelectionArea, and fitOnInit: surface feature toggles. Connection tools render only in edit mode.

Graph outputs

Listen for selectionChange, inspectedNodeIdChange, selectedExecutionIdChange, viewportChange, and executionActivated to keep inspection state synchronized. In edit mode, apply nodesMoved, nodeCreateRequested, connection create/reconnect/routing/waypoint requests, and node/connection delete requests to a new controlled definition snapshot. These outputs are proposals: the graph never mutates definition internally.

Controlled connection authoring

When accepting connectionCreateRequested, assign an application-owned ID, append the new connection with the request's resolved routing, and persist custom-point endpoint ports with ensureTngFlowCustomPointPorts(). Apply connectionsDeleteRequested by filtering those IDs from the definition, clearing stale selection, and calling pruneUnusedTngFlowCustomPointPorts().

The edit-mode canvas toolbar exposes straight, Bézier, orthogonal, rounded orthogonal, and adaptive styles at all times. Choosing one updates connectionCreationPathType and affects the live preview plus connections drawn afterward; it does not alter existing connections. Undo and Redo are visible disabled placeholders until history behavior is added. To restyle selected existing connections, call requestConnectionRoutingChange() and apply the resulting controlled connectionRoutingChangeRequested event.

Imperative helpers

The graph forwards layout and viewport helpers such as refreshLayout(), fitToScreen(), resetViewport(), centerNode(), and requestConnectionRoutingChange().
