Dagre Layout API

The secondary entry point supplies the Dagre engine. Engine-neutral types, configuration, and editor integration remain part of @tailng-ui/flow.

Adapter exports

Export Purpose
TNG_FLOW_DAGRE_LAYOUT_ENGINE Shared immutable Dagre engine for provider or input configuration.
createTngFlowDagreLayoutEngine<TNodeData, TConnectionData>() Creates a typed engine instance without exposing Dagre-specific graph types.

Engine contract

Primary entry-point API Purpose
TngFlowLayoutEngine Defines calculate(graph, options), which asynchronously returns node moves.
TngFlowLayoutGraph Measured node bounds plus graph connections supplied to the engine.
provideTngFlowLayoutEngine(engine) Registers the default engine for descendant Flow Editor instances.
TNG_FLOW_LAYOUT_ENGINE Injection token used by the provider and the editor.

Layout options

Option Default Purpose
direction 'left-to-right' Uses left-to-right, right-to-left, top-to-bottom, or bottom-to-top flow.
nodeSpacing 48 Separates nodes on the same rank.
levelSpacing 120 Separates graph ranks.
componentSpacing 64 Separates disconnected graph components.
preserveLockedNodes true Preserves locked coordinates and uses locked nodes as layout anchors.
includeDisconnectedNodes true Includes isolated nodes in the calculated result.
viewport.fit / animated / padding false / false / 48 Optionally fits the canvas after controlled positions are applied.

Flow Editor integration

Member Contract
layoutEngine Per-editor engine input that overrides the injected default.
requestAutoLayout(options?, source?) Returns Promise<boolean>; false means the editor could not start or safely apply the calculation.
nodesLayoutRequested Emits TngFlowNodesLayoutRequest with node moves, resolved options, viewport behavior, and request source.
