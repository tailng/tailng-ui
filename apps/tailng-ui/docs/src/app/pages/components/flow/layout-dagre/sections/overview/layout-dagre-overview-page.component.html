Dagre automatic layout

Add layered graph arrangement to Flow Editor without coupling the core editor to a particular layout algorithm.

Install

Install Dagre alongside @tailng-ui/flow. Dagre is an optional peer dependency, so applications that do not use this adapter do not need it.

Optional secondary entry point

Import the adapter from @tailng-ui/flow/layout-dagre. The primary @tailng-ui/flow entry point remains the stable home for Flow Editor and its engine-neutral layout contracts.

Configure an engine

Register the immutable shared engine at application bootstrap when every editor should use Dagre.

For per-editor generics or different engine choices, create an instance and pass it through the editor's layoutEngine input.

Controlled layout contract

Calling requestAutoLayout() measures the rendered graph and asks Dagre for new coordinates. Flow Editor then emits nodesLayoutRequested; your application owns the immutable update that writes those positions back to the workflow.

This keeps automatic layout undoable, persistable, and compatible with external state stores. A requested viewport fit runs only after the controlled positions have rendered.
