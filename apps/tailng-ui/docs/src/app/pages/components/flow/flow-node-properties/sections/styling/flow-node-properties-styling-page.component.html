Panel layout

The node properties panel is designed for sidebars, drawers, and inspector columns. The host should own width and height while the component handles internal spacing and section rhythm.

Theme tokens

The panel follows the execution viewer theme for background, border, text, muted text, controls, and focus styles so it can sit beside the graph without a second visual system.

Readonly state

Use readonly mode for historical runs, locked workflows, or permission-limited users. The layout remains the same while editable controls become passive display fields.
