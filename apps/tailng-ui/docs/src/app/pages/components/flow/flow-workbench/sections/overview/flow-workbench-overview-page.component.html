Flow Workbench

Flow Workbench is a ready-made shell for creating, editing, viewing, inspecting, and monitoring workflows. It combines the execution-aware graph with optional palette and details panels while keeping workflow state controlled by the application.

Modes

Use create and edit for authoring, view for passive diagrams, inspect for node details, and live for execution history, payloads, and run status.

Composition

The workbench owns the common layout: left palette, center graph, and right or bottom details. Consumers can use the default node palette and default details, or replace either panel with projected templates.

State ownership

Applications still own definitions, selections, viewport, execution snapshots, and mutations. The workbench emits typed requests for creation, movement, selection, connection updates, and inspector changes.
