Selected node panel

Bind the same inspected node id used by the graph, then apply emitted changes to the definition in the parent component. 

<tng-flow-node-properties
  [definition]="definition()"
  [inspectedNodeId]="inspectedNodeId()"
  [readonly]="saving()"
  [showPorts]="true"
  [showData]="true"
  (nodeChangeRequested)="applyNodeChanges($event)"
/>

Custom data rendering

Use the data template when node payloads need a domain form, redacted fields, or a custom summary instead of the default JSON/text preview. 

<tng-flow-node-properties [node]="selectedNode()">
  <ng-template tngFlowNodePropertiesData let-node>
    <app-agent-node-settings [node]="node" />
  </ng-template>
</tng-flow-node-properties>
