Flow Execution Graph

Flow Execution Graph is the standalone workflow diagram used by the execution viewer. Use it when a product already owns the surrounding inspector, properties panel, routing, or layout but still needs the same execution-aware graph surface.

Responsibilities

The graph maps a workflow definition and run snapshot into node and connection presentation state. It controls selection, inspected node, selected execution, viewport forwarding, and execution activation events.

Boundary

The component does not render a property panel, execution history, payload viewer, or split layout. Pair it with Flow Node Properties or a product-owned inspector when users need details beside the diagram. Use Flow Editor when users need to move nodes, create or delete connections, or change connection routing.
