Responsibilities

The graph maps a workflow definition and run snapshot into node and connection presentation state. It controls selection, inspected node, selected execution, viewport forwarding, and execution activation events.

Boundary

The component does not render a property panel, execution history, payload viewer, or split layout. Pair it with Flow Node Properties or a product-owned inspector when users need details beside the diagram. Use mode="edit" when users need to move nodes or author connections, mode="inspect" for selection without mutations, and mode="readonly" for viewport-only interaction.
