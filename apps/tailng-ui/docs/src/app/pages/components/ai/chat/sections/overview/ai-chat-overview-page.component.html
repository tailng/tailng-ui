AI foundation

AI Chat

Build protocol-neutral AI chat features on a canonical message model, normalized state, cursor-paged history, and an optional AG-UI 1.0 streaming adapter.

Current scope: this package is the headless data and protocol foundation. It does not yet export a rendered Angular chat component or its CSS.

Imports

Install the core package. Add the AG-UI peer only when consuming the secondary adapter entry point.

Architecture

Application owns

Transport, persistence, authentication, message rendering, composer UI, virtualization, and product policy.

TailNG owns

Canonical types, safe lifecycle operations, normalized storage, cursor-history coordination, validation, and AG-UI event reduction.

Canonical model

Messages are stable envelopes containing ordered, typed parts. Keep transport-specific event objects outside renderers and reduce them into this model at the application boundary.

Memory strategy

Do not load an entire long conversation into the browser. Fetch older messages with opaque cursors, keep one normalized record per ID, render only a virtualized window, and retain drafts and summaries separately from the visible message window.

  • Start with 40 messages; the controller clamps pages to 100 by default.
  • Prepend older pages and preserve the scroll anchor in the rendering layer.
  • Abort in-flight history requests when the active thread changes.
  • Persist older pages outside component memory and evict them using an application policy.

AG-UI boundary

The AG-UI adapter validates official 1.0 events before reducing run, text, tool-call, tool-result, and message-snapshot events into the same store. Unsupported or invalid events return diagnostics instead of reaching the UI unchecked.
