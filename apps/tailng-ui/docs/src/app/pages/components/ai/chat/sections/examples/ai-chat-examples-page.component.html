Normalized store

Cursor history

AG-UI streaming

Pass decoded transport events to one reducer. Read the store after applied events and schedule rendering at most once per animation frame.

Long-chat memory checklist

  • Use cursor pagination instead of offset pagination or full-thread hydration.
  • Virtualize transcript rows and overscan only a small screen-adjacent window.
  • Batch token deltas before triggering Angular change detection.
  • Move Markdown parsing, highlighting, and large attachment work off the hot render path.
  • Evict inactive thread pages while retaining cursors, summaries, and unsent drafts.
  • Abort history and streaming work when a thread is closed or replaced.
