Working chat demo

Type hi, choose one of twelve prompts grouped across Forms, Data, Navigation & layout, and Feedback, and watch real AG-UI events reduce into the normalized store. The assistant streams a correlated render_component tool lifecycle before an allowlisted TailNG datepicker, chart, validated TailNG preview into the transcript. Options include date controls, autocomplete, slider, charts, table, accordion, tabs, stepper, tags, and progress. Stop and retry a response or prepend a cursor-loaded history page. New content stays in view while you follow the conversation; scrolling up pauses that behavior and shows a Jump to latest control. The simulation is deterministic and runs entirely in this page.

Safe component renderers

AG-UI carries the run, message, and tool lifecycle. Component choices are application-owned extension parts. Validate their version and payload at the boundary, then resolve only known IDs from a local registry. Never accept a selector, import path, Angular template, or HTML from an agent response.

Normalized store

Store each entity once and derive an ordered message projection only for the active thread.

Cursor history

Return messages oldest-to-newest within each page. The controller validates the page and prepends it without duplicating IDs.

AG-UI streaming

Pass decoded transport events to one reducer. Read the store after applied events and schedule rendering at most once per animation frame.

Long-chat memory checklist

  • Use cursor pagination instead of offset pagination or full-thread hydration.
  • Virtualize transcript rows and overscan only a small screen-adjacent window.
  • Batch token deltas before triggering Angular change detection.
  • Move Markdown parsing, highlighting, and large attachment work off the hot render path.
  • Evict inactive thread pages while retaining cursors, summaries, and unsent drafts.
  • Abort history and streaming work when a thread is closed or replaced.
