Required styles

Import the Flow Editor stylesheet once. The execution viewer reuses the graph CSS variables and adds inspector/payload classes from the execution entry point. 

@import '@tailng-ui/flow/styles.css';

Responsive inspector

Use inspectorPosition="auto" for production embeds. It renders the inspector on the right for wide surfaces and switches to a bottom pane below the configured breakpoint.

Dark mode

The viewer follows TailNG semantic tokens. Scope dark tokens on a parent container when an embedded workflow monitor must differ from the surrounding app theme.

Payload density

Keep payload panes scrollable and prefer redacted or summarized payload records for sensitive or very large values. The default payload renderer wraps JSON safely and preserves compact inspector layout.
