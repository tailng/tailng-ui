Flow Execution Viewer

Flow Execution Viewer is a controlled read-only surface for rendering workflow run snapshots against a Flow Editor definition. It combines the graph, phase/progress presentation, execution history, payload rendering, and a responsive inspector.

Import

import { TngFlowExecutionViewerComponent } from '@tailng-ui/flow/execution';

State ownership

Your application owns the workflow definition, execution snapshot, selected graph items, inspected node, selected execution, and viewport. The viewer renders that state and emits typed updates when users inspect the graph or execution history.

Snapshot contract

Snapshots are append-friendly records keyed by node, connection, activation, and attempt. Pending, active, waiting, succeeded, failed, skipped, cancelled, and idle phases map to graph presentation without consumers hand-authoring node view state.

Accessibility baseline

Provide a specific ariaLabel, keep the viewer controlled, and expose meaningful status messages for live execution states. The details pane is keyboard reachable and can be hidden when the embedding surface is too small.
