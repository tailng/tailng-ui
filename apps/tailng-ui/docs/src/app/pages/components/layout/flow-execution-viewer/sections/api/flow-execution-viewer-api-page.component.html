Viewer inputs

The required pair is definition plus snapshot. Control selection, inspection, viewport, mode, inspector position, minimap, and payload formatting through the remaining inputs.

  • definition: workflow graph definition.
  • snapshot: run, node, and connection execution state.
  • selection, inspectedNodeId, selectedExecutionId.
  • inspectorPosition: auto, right, or bottom.
  • state: ready, loading, empty, or error.

Viewer outputs

The viewer emits controlled-state updates for selection, inspected node, selected execution, viewport, inspector visibility, and execution activation.

Execution models

Use TngFlowRunExecutionSnapshot, TngFlowNodeExecution, TngFlowConnectionExecution, and TngFlowExecutionPayload from the execution entry point.

Template hooks

Override inspector content with ng-template[tngFlowExecutionInspector] or payload rendering with ng-template[tngFlowExecutionPayload] when product-specific summaries, redaction copy, or JSON viewers are required.
