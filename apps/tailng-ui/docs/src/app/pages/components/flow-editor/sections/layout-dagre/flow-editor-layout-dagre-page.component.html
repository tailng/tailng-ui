Dagre automatic layout

Flow Editor keeps automatic layout engine-neutral and opt-in. The official Dagre adapter is a secondary entry point, so applications that do not use it do not load Dagre.

Install

Install Dagre alongside Flow Editor only when the adapter is needed.

Configure the engine

Register the shared engine at application bootstrap, or create an engine and pass it through the editor's layoutEngine input when one canvas needs different behavior.

Controlled layout demo

Dagre calculates positions but never mutates application state. The editor emits one complete request, and this page writes those positions back to its controlled workflow definition.

Layout options

Option Purpose
direction Chooses horizontal or vertical graph flow.
nodeSpacing Sets separation between nodes on one rank.
levelSpacing Sets separation between graph ranks.
componentSpacing Separates disconnected graph components.
preserveLockedNodes Keeps locked nodes at their controlled positions.
includeDisconnectedNodes Includes isolated nodes in the result.
viewport Optionally fits the viewport after positions are applied.

Adapter API

Use TNG_FLOW_DAGRE_LAYOUT_ENGINE for a shared immutable engine. Use createTngFlowDagreLayoutEngine<TNodeData, TConnectionData>() when generic application data should flow through the engine type.

Both exports come from @tailng-ui/flow/layout-dagre. Engine-neutral layout types, the provider, and editor methods remain in @tailng-ui/flow.
