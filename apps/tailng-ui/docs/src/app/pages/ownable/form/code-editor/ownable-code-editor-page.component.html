Code Editor

The ownable Code Editor install gives your app local control over the native textarea, synchronized highlighting overlay, and adapter configuration.

Why own Code Editor locally

  • Choose languages and themes without bundling a highlighter into the component.
  • Add product-specific commands while preserving the native editing surface.
  • Adjust editor dimensions and tokens alongside application layouts.

What the install includes

The registry writes the component, overlay template, styles, local highlighting contract, and export barrel. It does not install Shiki or another highlighting engine.
