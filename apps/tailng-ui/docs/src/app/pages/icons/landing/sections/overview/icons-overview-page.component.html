Icons

@tailng-ui/icons provides a lazy-loading icon system with built-in Lucide support and an extensible pack API for any SVG icon set.

Getting Started
Installation Install the icons package along with the @ng-icons peer dependencies for Lucide (the default built-in pack).
Configuration
Default Setup - Lucide Icons Call provideTngIcons() in your application config. With no arguments, Lucide is registered as the default pack.
Basic Usage Import TngIcon and use the <tng-icon> element. Icons load lazily on first use. Icon Reference Syntax Icon names can be plain, resolved against the default pack, or prefixed with pack-name: to reference a specific pack.
